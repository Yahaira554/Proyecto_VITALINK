# Sistema de Accesibilidad Mejorado de VitaLink

## 🎤 Comandos por Voz

VitaLink ahora incluye un sistema completo de control por voz diseñado específicamente para personas con dificultades motrices o visuales.

### Cómo Activar

1. **Busca el botón azul flotante** en la esquina inferior derecha (ícono de micrófono)
2. **Presiona el botón** o tócalo para activar los comandos de voz
3. Cuando el micrófono esté activo, el botón se volverá **rojo y parpadeará**
4. Verás un indicador "Escuchando..." cuando el sistema esté captando tu voz

### Comandos Disponibles

#### 🧭 Navegación
- "Inicio" / "Ir a inicio" / "Panel principal"
- "Medicamentos" / "Ir a medicamentos" / "Mis medicinas"
- "Salud" / "Ir a salud" / "Mis datos de salud"
- "Familia" / "Ir a familia" / "Red familiar"
- "Chat" / "Ir a chat" / "Mensajes"
- "Perfil" / "Mi perfil"

#### ⚡ Acciones Rápidas
- "Emergencia" / "Ayuda" / "Socorro" - Activa la alerta de emergencia
- "Cerrar sesión" / "Salir de la aplicación" / "Terminar sesión" - Cierra tu sesión
- "Atrás" / "Regresar" / "Volver" - Vuelve a la pantalla anterior
- "Cerrar" / "Salir" - Cierra modales y alertas
- "Menú" / "Abrir menú" - Abre el menú de navegación
- "Accesibilidad" / "Opciones" - Abre opciones de accesibilidad

#### 💬 Ayuda
- "Ayuda de voz" / "Qué puedo decir" / "Comandos" - Muestra todos los comandos disponibles

### Características Especiales

✅ **Reconocimiento continuo**: El sistema escucha constantemente cuando está activo
✅ **Feedback en tiempo real**: Ves lo que el sistema está escuchando
✅ **Confirmación por voz**: El sistema confirma cada acción ejecutada
✅ **Reinicio automático**: Si se interrumpe, el sistema se reinicia automáticamente
✅ **Adaptativo**: Funciona mejor con el uso

### Consejos para Mejor Reconocimiento

1. **Habla claro y pausado**
2. **Usa un ambiente silencioso** cuando sea posible
3. **Mantén una distancia adecuada** del micrófono (30-60 cm)
4. **No es necesario gritar**, habla en tono normal
5. **Di el comando completo** sin interrupciones

## 🌍 Soporte Multilingüe e Inclusión Indígena

VitaLink es la primera aplicación de salud en México que incluye soporte completo para lenguas indígenas de Jalisco.

### Idiomas Disponibles

#### 🇲🇽 Español (México)
- Idioma principal de la aplicación
- Síntesis de voz completa
- Comandos de voz en español

#### 🏔️ Wixárika (Huichol)
- Lengua del pueblo wixárika del norte de Jalisco
- Traducciones adaptadas culturalmente
- Términos médicos en wixárika
- Ejemplo: "Nierika" (Salud), "Hapuene" (Medicamentos)

#### 🌄 Náhuatl
- Lengua náhuatl del sur de Jalisco
- Preservación de términos médicos tradicionales
- Ejemplo: "Yoliztli" (Salud), "Pahtli" (Medicina)

#### 🌺 P'urhépecha (Purépecha)
- Lengua purépecha de comunidades de Jalisco
- Vocabulario médico adaptado
- Ejemplo: "Iretarhu" (Salud), "Jarhasti" (Medicina)

#### 🇺🇸 English
- Para usuarios internacionales
- Síntesis de voz en inglés

### Cómo Cambiar el Idioma

1. **Abre el menú de accesibilidad** (botón morado en la esquina superior derecha)
2. En la primera sección verás **"Idioma / Language"**
3. Presiona el botón con la bandera actual
4. **Selecciona tu idioma preferido** de la lista
5. Puedes **escuchar una muestra** presionando el ícono de bocina
6. Tu selección se guardará automáticamente

### Características del Sistema de Traducción

✅ **Traducciones culturalmente adaptadas**: No solo traducciones literales
✅ **Términos médicos especializados**: Vocabulario médico en cada lengua
✅ **Instrucciones de medicamentos**: En tu idioma preferido
✅ **Síntesis de voz**: El sistema lee en tu idioma
✅ **Persistencia**: Tu idioma se guarda entre sesiones

### Comandos de Voz en Wixárika

Además del español, algunos comandos básicos funcionan en wixárika:

- "Temuki" - Inicio
- "Hapuene" - Medicamentos  
- "Nierika" - Salud
- "Yukali" - Familia
- "Neixa" - Chat
- "Nakawe" - Emergencia
- "Tupari" - Regresar
- "Tepu'uka" - Cerrar

## ♿ Funciones de Accesibilidad Adicionales

### 🔊 Lectura por Voz
- Lee automáticamente el contenido de cada pantalla
- Velocidad ajustable (Muy lenta, Lenta, Normal, Rápida)
- Volumen ajustable
- Pausar/reanudar en cualquier momento

### 👁️ Alto Contraste
- Aumenta el contraste de colores
- Mejora la legibilidad para personas con baja visión
- Colores optimizados para discapacidades visuales

### 📝 Texto Muy Grande
- Aumenta el tamaño de todo el texto
- Botones más grandes y fáciles de presionar
- Espaciado optimizado

### 🎯 Modo Simplificado
- Interfaz más simple con menos opciones
- Botones extra grandes
- Navegación más directa
- Menos distracciones visuales

### 🔄 Lectura Automática
- Lee automáticamente al abrir cada pantalla
- Ayuda a entender el contenido sin necesidad de leer
- Ideal para personas con dificultades de lectura

Este sistema de accesibilidad está diseñado específicamente para:

- ✅ **Adultos mayores** con dificultades motrices o visuales

- ✅ **Personas con dificultades de lectura** o analfabetismo
- ✅ **Cualquier persona** que prefiera interactuar por voz

## 🚀 Cómo Empezar

### Para Usuarios con Dificultades Visuales

1. **Activa la lectura por voz** desde el menú morado (esquina superior derecha)
2. Escucha las instrucciones de cada pantalla
3. Usa **comandos de voz** para navegar sin tocar la pantalla
4. Ajusta el **tamaño del texto** y **contraste** según necesites

### Para Hablantes de Lenguas Indígenas

1. **Abre el menú de accesibilidad** (botón morado)
2. Selecciona tu **idioma preferido** (Wixárika, Náhuatl o P'urhépecha)
3. La aplicación ahora mostrará contenido en tu lengua
4. Los términos médicos estarán adaptados culturalmente

### Para Usuarios con Dificultades Motrices

1. **Activa los comandos de voz** (botón azul flotante)
2. Usa tu voz para navegar: "ir a medicamentos", "emergencia", etc.
3. Activa el **modo simplificado** para botones más grandes
4. Usa comandos de voz en lugar de tocar la pantalla

## 🔧 Solución de Problemas

### El reconocimiento de voz no funciona
- ✅ Verifica que hayas dado permiso de micrófono al navegador
- ✅ Prueba en un lugar más silencioso
- ✅ Asegúrate de que tu micrófono esté funcionando
- ✅ Intenta usar Chrome o Edge

### La síntesis de voz no se escucha
- ✅ Verifica el volumen de tu dispositivo
- ✅ Revisa que la lectura por voz esté activada en el menú morado
- ✅ Ajusta el volumen en las opciones de accesibilidad

### El idioma no cambia
- ✅ Cierra y vuelve a abrir el menú de accesibilidad
- ✅ Refresca la página
- ✅ Verifica que hayas presionado "Cerrar" para guardar
